# O que é git

Git é um sistema de controle de versão que nos auxilia a desenvolver software. Ele faz isso nos possibilitando visualizar o histórico de alterações, entender quando e porque uma mudança foi feita no código, e se necessário, volar para uma versão antiga do software. Além disso, ele torna mais fácil o desenvolvimento COLABORATIVO de software, com o conceito de branches.

Se você ainda não entendeu nada, não se preocupe, os próximos vão te ajudar nisso.
